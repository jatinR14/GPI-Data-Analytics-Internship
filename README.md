# GPI Data Analytics Internship

**StudentSalaryScope** — Data Analytics internship project focused on analyzing student academic performance, economic background, technical skills, and expected salary.

## Dataset

The dataset was provided by Cloud Counselage and contains **4,894 rows and 16 columns** of student event registration data collected through the IAC platform across India. The project uses this real-world dataset to derive data-driven insights into student competencies, academic performance, economic background, and salary expectations.

## Contents

- **Code** — Python/Jupyter Notebook
- **Deliverables** — Project documentation and Power BI dashboard
- **Output Data** — Project demo video and analysis outputs

## Key Highlights

- 4,894 student event records
- 2,157 unique students
- 16 unique events
- 17 analytical questions
- Python-based EDA and visualization
- Interactive Power BI dashboard
